Schoolnetwerk met MLS inter-VLAN routing, zelf gekozen root bridge (Rapid PVST+) en DHCP per VLAN. VLANs: Studenten, Lectoren, Management.

Taak 05
Rapid PVST+ — bepaal zelf de root bridge
cisco iosconfig
›

De opdracht zegt "bepaal zelf de root" — dit betekent dat je een bewuste keuze maakt. Logisch: de centrale switch (MLS-1) wordt root omdat al het verkeer toch via hem gaat.

! Op alle switches spanning-tree mode rapid-pvst ! MLS-1 als root voor alle VLANs (laagste priority) spanning-tree vlan 10 root primary spanning-tree vlan 20 root primary spanning-tree vlan 99 root primary ! Verifiëren wie de root bridge is show spanning-tree vlan 10 | include Root
Root bridge kiezen — waarom?Als je niets configureert, wint de switch met het laagste MAC-adres. Dat kan een random edge-switch zijn — slecht voor performance. Kies bewust de centrale/krachtigste switch als root.
Taak 06
Inter-VLAN routing op MLS-1
cisco iosconfig
›

MLS-1 is een Layer 3 switch. Activeer IP routing en maak SVIs aan als default gateways voor de VLANs.

! IP routing activeren (cruciaal!) ip routing ! SVI per VLAN interface vlan 10 ip address 172.16.10.1 255.255.255.0 no shutdown exit interface vlan 20 ip address 172.16.20.1 255.255.255.0 no shutdown exit interface vlan 99 ip address 172.16.99.1 255.255.255.0 no shutdown exit ! Routed port naar R-1 (DHCP server) interface GigabitEthernet1/0 no switchport ip address 172.16.1.1 255.255.255.252 no shutdown exit ! Default route naar R-1 ip route 0.0.0.0 0.0.0.0 172.16.1.2 show ip route
⚠ no switchportOp een L3 switch zijn poorten standaard switch-poorten. Gebruik no switchport op een poort om er een routed (layer 3) poort van te maken — dan kan je er een IP op zetten.
