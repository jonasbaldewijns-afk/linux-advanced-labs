Lab 07 · Networks Advanced

Technology Innovation & Solutions

Bedrijfsnetwerk met meerdere VLANs, MLS inter-VLAN routing en Wi-Fi VLAN. Beschikbaar in v1.0 (SW-1+MLS) en v2.0 (MLS vervangt SW-1 + webserver).

Opstel
Taak 01
Topologie opbouwen in Packet Tracer
packet traceropstel
›

Bouw de onderstaande topologie op in Packet Tracer vóór je begint met configureren.

Apparaten:

  • 1x Layer-3 Switch 3560 (MLS-1)
  • 3x Switch 2960-24TT (SW-2, SW-3, SW-4)
  • 1x PC (PC-0 — Sales)
  • 3x Laptop (Laptop-2 Projects, Laptop-3 Corporate, Laptop-4 Wi-Fi)
  • 1x Server (v2.0 — Webserver, optioneel)
  • 1x Access Point (v2.0 — voor Wi-Fi VLAN, optioneel)

Kabeltypes in PTStraight-through: PC/server → switch, switch → router. Cross-over: switch → switch, router → router (Ethernet). Automatisch: PT detecteert het juiste type als je "Automatically Choose" selecteert.
⚠ Packet Tracerv1.0 heeft een aparte SW-1 als L2 switch naast MLS-1. v2.0 vervangt SW-1 door MLS-1 (de L3 switch neemt zijn positie over) en voegt een webserver toe. Bouw v2.0 als standaardversie — dat is de meest recente opdracht.
Theorie
Theorie 02
VLAN-plan en adresschema
theorie
›

Dit netwerk heeft 7 VLANs. De nummers zijn bewust niet opeenvolgend — ze zijn gekozen op basis van rol/functie.

VLANNaamSubnetHosts
3ParkingLot—Ongebruikte poorten
8Wi-Fi10.10.8.0/24Draadloze clients
10Sales10.10.10.0/24PC-0
13Native—Trunk native
20Projects10.10.20.0/24Laptop-2
27Management10.10.27.0/24Switch mgmt
30Corporate10.10.30.0/24Laptop-3, Webserver
ℹ AdresschemaHet schema is 10.10.VlanID.0/24. Dus VLAN 10 → 10.10.10.0/24, VLAN 20 → 10.10.20.0/24, etc. Merk op dat VLAN 8 → 10.10.8.0/24 — ook voor Wi-Fi.

Taak 05
Trunk links configureren
cisco iosconfig
›

Native VLAN = 13. Alle trunk links moeten identieke native VLAN hebben.

! Op SW-2 (trunk naar MLS-1) interface GigabitEthernet0/1 switchport mode trunk switchport trunk native vlan 13 switchport trunk allowed vlan 3,8,10,13,20,27,30 switchport nonegotiate exit ! Zelfde config op SW-3 en SW-4
⚠ Native VLAN mismatchAls native VLAN op de twee kanten van een trunk verschilt, geeft PT/CDP een waarschuwing: "Native VLAN mismatch". Alle trunk poorten moeten native vlan 13 hebben.

Taak 07
v2.0 — Webserver toevoegen
cisco iosconfig
›

De webserver staat in het Corporate VLAN (30) en heeft een statisch IP.

! SW-4: webserver-poort interface FastEthernet0/2 switchport mode access switchport access vlan 30 spanning-tree portfast exit

Configureer de webserver in PT:

  • Klik op Server → Config → FastEthernet: IP 10.10.30.100/24, gateway 10.10.30.1
  • Services → HTTP: zet aan
  • Test: open browser op PC-0 → ga naar http://10.10.30.100
ℹ HTTP test in PTGebruik de Desktop-tab van een PC in PT → Web Browser → typ het IP van de webserver. Als de inter-VLAN routing correct is, laadt de standaard Packet Tracer webpagina.
