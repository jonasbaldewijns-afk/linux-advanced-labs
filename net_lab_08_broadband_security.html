Broadband Access & Layered Security

Het meest complexe lab: HSRP, 6 Etherchannels, DHCP snooping, Dynamic ARP Inspection en Port Security in één topologie.

Bouw de onderstaande topologie op in Packet Tracer vóór je begint met configureren.

Apparaten:

  • 1x Layer-3 Switch 3560 (MLS)
  • 4x Switch 2960-24TT (SW-1, SW-2, SW-3, SW-4)
  • 1x Server (DHCP-server)

Taak 06
DHCP snooping
cisco iossecurity
›

Voorkomt dat een nep-DHCP-server valse IP-adressen uitdeelt aan clients.

! Op alle switches ip dhcp snooping ip dhcp snooping vlan 10,20,30,99 no ip dhcp snooping information option ! Vertrouwde poort richting echte DHCP-server/MLS interface GigabitEthernet0/1 ip dhcp snooping trust exit ! Alle andere poorten zijn automatisch untrusted show ip dhcp snooping show ip dhcp snooping binding
Trusted vs Untrusted portsOp een untrusted poort worden DHCP OFFER en ACK berichten gedropt — alleen DISCOVER en REQUEST mogen. Dit voorkomt dat een client-apparaat zelf DHCP-aanbiedingen stuurt. Trusted ports zijn richting de echte DHCP-server of andere switches.
Taak 07
Dynamic ARP Inspection (DAI)
cisco iossecurity
›

DAI controleert ARP-pakketten aan de hand van de DHCP snooping-tabel en gooit valse ARP-antwoorden weg.

! DHCP snooping moet al actief zijn (taak 06) ! Op alle switches ip arp inspection vlan 10,20,30,99 ! Vertrouwde poort interface GigabitEthernet0/1 ip arp inspection trust exit show ip arp inspection show ip arp inspection vlan 10
⚠ Volgorde is cruciaalActiveer DHCP snooping vóór DAI. DAI gebruikt de snooping-bindingtabel om te valideren of een ARP-antwoord klopt (IP↔MAC-combinatie). Zonder snooping verwerpt DAI al het ARP-verkeer.

! Op alle access ports interface FastEthernet0/10 switchport port-security switchport port-security maximum 1 switchport port-security mac-address sticky switchport port-security violation restrict exit ! Violation modes: ! protect — dropt frames, geen log, geen counter ! restrict — dropt frames + syslog + counter ! shutdown — poort in err-disabled (meest strikt) show port-security show port-security interface FastEthernet0/10
