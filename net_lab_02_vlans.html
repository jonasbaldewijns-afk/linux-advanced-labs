VLANs & Trunking

Segmenteer een netwerk met VLANs, configureer 802.1Q trunk links en beveilig ongebruikte poorten met een parkinglot-VLAN.

Theorie
Theorie 02
VLANs en 802.1Q trunking begrijpen
theorie
›

Een VLAN segmenteert een fysiek netwerk in logische deelnetwerken. Hosts in verschillende VLANs kunnen zonder router niet met elkaar communiceren — ook al zitten ze op dezelfde fysieke switch.

ConceptUitlegVoorbeeld
VLANLogisch netwerksegmentVLAN 10 = Sales
Access portPoort in één VLAN (voor hosts)Fa0/1 → VLAN 10
Trunk portPoort die meerdere VLANs draagt (802.1Q tags)Gi0/1 tussen switches
Native VLANVLAN voor untagged frames op trunkVLAN 99
ParkinglotOngebruikte poorten — uitgeschakeldVLAN 999

IP-schema voor dit lab:

VLANNaamSubnetHosts
10Sales192.168.10.0/24PC-Sales
20Engineering192.168.20.0/24PC-Eng
99Management/Native192.168.99.0/24Switch mgmt
999Parkinglot—Ongebruikte poorten
Waarom een Native VLAN?Op een trunk worden frames getagd met hun VLAN-ID. Frames van het native VLAN worden echter niet getagd. Gebruik nooit VLAN 1 als native VLAN — dat is een bekend aanvalspunt (VLAN hopping). Gebruik een dedicated VLAN zoals 99.
Configuratie
Taak 03
VLANs aanmaken op beide switches
cisco iosconfig
›

Maak alle VLANs aan op elk switch. VLANs bestaan enkel lokaal op de switch — ze worden niet automatisch gesynchroniseerd (tenzij VTP actief is).

! Op SW1 ÉN SW2 uitvoeren vlan 10 name Sales vlan 20 name Engineering vlan 99 name Management vlan 999 name Parkinglot exit show vlan brief
⚠ VLAN 1 — Gebruik VLAN 1 nooit als management- of native VLAN. Het is het standaard-VLAN en een bekend doelwit voor VLAN hopping-aanvallen.
Taak 04
Access ports configureren
cisco iosconfig
›

Wijs elke host-poort toe aan het juiste VLAN. Een access port draagt slechts één VLAN en stuurt geen tags.

! Op SW1 interface FastEthernet0/1 switchport mode access switchport access vlan 10 spanning-tree portfast exit interface FastEthernet0/2 switchport mode access switchport access vlan 20 spanning-tree portfast exit ! Op SW2 — zelfde patroon interface FastEthernet0/1 switchport mode access switchport access vlan 10 spanning-tree portfast exit
spanning-tree portfastLaat een access port direct in forwarding-state gaan, zonder de normale STP listening/learning-fasen te doorlopen (normaal 30 seconden wachten). Gebruik uitsluitend op access ports richting hosts — nooit op trunk ports.
ℹ PC IP-adressen instellenStel op PC-Sales in PT een statisch IP in: 192.168.10.10/24, gateway 192.168.10.1 (nog niet actief — later bij inter-VLAN). Op PC-Eng: 192.168.20.10/24.
Taak 05
Trunk port configureren tussen SW1 en SW2
cisco iosconfig
›

De trunk draagt alle VLAN-verkeer tussen de twee switches. Native VLAN moet identiek zijn op beide kanten.

! Op SW1 — Gi0/1 naar SW2 interface GigabitEthernet0/1 switchport mode trunk switchport trunk native vlan 99 switchport trunk allowed vlan 10,20,99 switchport nonegotiate exit ! Op SW2 — Gi0/1 naar SW1 (identieke config) interface GigabitEthernet0/1 switchport mode trunk switchport trunk native vlan 99 switchport trunk allowed vlan 10,20,99 switchport nonegotiate exit
✓ Verificatieshow interfaces trunk — toont trunk ports, native VLAN en allowed VLANs
show interfaces Gi0/1 switchport — gedetailleerde info van één poort
Taak 06
DTP uitschakelen en parkinglot instellen
cisco iossecurity
›

DTP (Dynamic Trunking Protocol) onderhandelt automatisch over trunk-modus — dit is een veiligheidsrisico. Schakel het uit op alle poorten.

! DTP uitschakelen op trunk: switchport nonegotiate (al gedaan in taak 05) ! Parkinglot: ongebruikte poorten interface range FastEthernet0/3-24 switchport mode access switchport access vlan 999 shutdown exit ! CDP uitschakelen op externe poorten (geen device-info lekken) interface FastEthernet0/1 no cdp enable exit
ℹ Wat is DTP?DTP is een Cisco-protocol dat automatisch trunk-verbindingen opzet tussen switches. Het probleem: een aanvaller kan zelf ook DTP sturen en zo een trunk forceren naar zijn eigen apparaat — waarna hij toegang heeft tot alle VLANs.
Taak 07
Switch management-IP en verificatie
cisco iosverificatie

Stel de management-IP in op VLAN 99 zodat je de switch via SSH kan bereiken.

! Op SW1 interface vlan 99 ip address 192.168.99.2 255.255.255.0 no shutdown exit ip default-gateway 192.168.99.1 ! Op SW2 interface vlan 99 ip address 192.168.99.3 255.255.255.0 no shutdown exit ip default-gateway 192.168.99.1

ℹ ConnectiviteitstestPing van PC-Sales naar PC-Eng zal niet werken — ze zitten in verschillende VLANs. Dit is correct! Voor inter-VLAN verkeer heb je een router of MLS nodig (zie labs 06-09).
Taak 08
Troubleshooting — veelgemaakte fouten
verificatie
›

Als iets niet werkt, doorloop deze checklist:

  1. VLAN bestaat niet op de switch — show vlan brief: staat het VLAN er? Maak het aan als het ontbreekt.
  2. Trunk native VLAN mismatch — show interfaces trunk: native VLAN hetzelfde op beide kanten?
  3. VLAN niet allowed op trunk — is VLAN 10 wel in de allowed-lijst van de trunk?
  4. Access port in verkeerd VLAN — show interfaces Fa0/1 switchport: klopt het access VLAN?
  5. STP blokkeert poort — show spanning-tree vlan 10: is de poort in FWD of BLK?
! Snel troubleshoot-commando show vlan brief show interfaces trunk show spanning-tree vlan 10 brief
