Theorie 01
Multi-master replicatie begrijpen
theorie
›

In Active Directory kan elke DC wijzigingen doorvoeren. Dit heet multi-master replicatie — er is geen single primary server nodig.

Hoe werkt het?Elke wijziging op een DC wordt lokaal opgeslagen in NTDS.dit. Daarna stuurt de DC een replicatieverzoek naar zijn partners (pull-model). DC's gebruiken USN (Update Sequence Numbers) om bij te houden welke wijzigingen nog gesynchroniseerd moeten worden.
TermUitleg
USNUpdate Sequence Number — uniek volgnummer per wijziging op een DC
KCCKnowledge Consistency Checker — bepaalt replicatietopologie automatisch
repadminCLI-tool voor replicatiebeheer en -diagnose
ℹ Info — Standaard repliceert AD binnen een site elke 15 seconden, tussen sites elke 15 minuten (configureerbaar via Sites and Services).
Theorie 02
Global Catalog Server en FSMO-rollen kennen
theorie
›

De Global Catalog (GC) is een DC die een gedeeltelijke kopie bijhoudt van alle objecten in het volledige AD-forest. Noodzakelijk voor inloggen en Universal Group membership.

FSMO-rollen — 5 speciale rollen die slechts op één DC tegelijk mogen staan:

FSMO-rolFunctieScope
Schema MasterWijzigingen aan AD-schemaForest
Domain Naming MasterDomeinen toevoegen/verwijderenForest
PDC EmulatorTijdsynchronisatie, wachtwoord policiesDomein
RID MasterUnieke SIDs toewijzen aan objectenDomein
Infrastructure MasterVerwijzingen naar objecten in andere domeinenDomein
netdom query fsmo

Toont welke DC welke FSMO-rollen heeft. Na het toevoegen van een tweede DC staan alle rollen nog op DC1 — dit is normaal.

Taak 03
WINADV-DD2 aanmaken en joinen aan het domein
installatieconfig
›

Maak een nieuwe Windows Server 2025 VM aan met de naam WINADV-DD2 en voeg die toe aan het domein pxldigital.local.

VM aanmaken:

  • Installeer Windows Server 2025 (zelfde procedure als Lab 01)
  • Geef de server de naam WINADV-DD2
  • Stel een statisch IP in hetzelfde subnet als DC1
  • DNS-server: IP-adres van WINADV-DC1XX (DC1 is de DNS-server)

Joinen aan het domein:

  • Settings → System → About → "Domain or workgroup" → Change → Domain: pxldigital.local

  • Via PowerShell (op WINADV-DD2):

    Add-Computer -DomainName "pxldigital.local" -Credential (Get-Credential) -Restart
    Gebruik domain Administrator-credentials
  • Herstart na het joinen

Juiste OU:

  • Na het joinen staat de server standaard in de container Computers

  • Via PowerShell (op DC1):

    $dc2 = Get-ADComputer "WINADV-DD2" Move-ADObject -Identity $dc2 -TargetPath "OU=Domain Controllers,DC=pxldigital,DC=local"
    Open ADUC op DC1 → verplaats WINADV-DD2 naar de OU Domain Controllers
✔ VerificatieIn ADUC op DC1 is WINADV-DD2 zichtbaar in de OU Domain Controllers.
Taak 04
WINADV-DD2 promoveren als additionele Domain Controller
config
›

Installeer de AD DS-rol op DD2 en promoveer de server als tweede DC in het bestaande domein.

AD DS-rol installeren:

  • Server Manager → Manage → Add Roles and Features

  • Via PowerShell:

    Install-WindowsFeature AD-Domain-Services -IncludeManagementTools
    Vink aan: Active Directory Domain Services (+ DNS Server)
  • Install → wacht tot klaar

Promoveren als additionele DC:

  • Klik op de gele waarschuwing → "Promote this server to a domain controller"
  • Kies: Add a domain controller to an existing domain
  • Domein: pxldigital.local — gebruik domain admin credentials
  • Vink aan: DNS Server, Global Catalog

  • Via PowerShell — promoveren als additionele DC:

    Install-ADDSDomainController ` -DomainName "pxldigital.local" ` -InstallDns ` -Credential (Get-Credential) ` -SafeModeAdministratorPassword (ConvertTo-SecureString "P@ssw0rd!" -AsPlainText -Force) ` -Force
    Stel een DSRM-wachtwoord in → Next → Install
  • Server herstart automatisch na promotie
✔ VerificatieIn ADUC op DC1: WINADV-DD2 verschijnt in de OU Domain Controllers als volwaardige DC. Replicatie start automatisch.

Theorie 05
Replicatie verifiëren met repadmin
testdebug
›

Gebruik repadmin op DC1 om de replicatiestatus te controleren.

repadmin /replsummary

Geeft een samenvatting van de replicatiestatus per DC — ideaal voor een snelle OK/NOK check.

repadmin /showrepl

Toont gedetailleerde replicatiepartners en de tijdstempel van de laatste synchronisatie.

repadmin /syncall /AdeP

Forceert onmiddellijke replicatie van alle partities naar alle partners. Gebruik dit na een configuratiewijziging om niet te wachten op het standaard interval.

✔ VerificatieGeen fouten in de output van replsummary. Maak een testgebruiker aan op DC1 en controleer of die na een korte wacht of na /syncall ook zichtbaar is op DD2.

De hogeschool neemt IT-medewerkers aan. Maak de structuur aan in AD.

OU aanmaken:

  • In ADUC: rechtsklik op OU=Users → New → Organizational Unit → naam: IT

Gebruikers aanmaken in OU IT:

NaamLogon name
Lars van Dijklars.van.dijk
Fatima El Amranifatima.el.amrani

Via PowerShell:

$pw = ConvertTo-SecureString "TestTest2025" -AsPlainText -Force $it = "OU=IT,OU=Users,DC=pxldigital,DC=local" New-ADOrganizationalUnit -Name "IT" -Path "OU=Users,DC=pxldigital,DC=local" New-ADUser -Name "Lars van Dijk" -SamAccountName "lars.van.dijk" -Path $it -AccountPassword $pw -Enabled $true New-ADUser -Name "Fatima El Amrani" -SamAccountName "fatima.el.amrani" -Path $it -AccountPassword $pw -Enabled $true New-ADUser -Name "Thomas Jansen" -SamAccountName "thomas.jansen" -Path $it -AccountPassword $pw -Enabled $true $grp = "OU=Groups,DC=pxldigital,DC=local" New-ADGroup -Name "GL_IT" -GroupScope Global -GroupCategory Security -Path $grp New-ADGroup -Name "DL_IT" -GroupScope DomainLocal -GroupCategory Security -Path $grp Add-ADGroupMember -Identity "GL_IT" -Members "lars.van.dijk","fatima.el.amrani","thomas.jansen" Add-ADGroupMember -Identity "DL_IT" -Members "GL_IT"
Groepen aanmaken in OU Groups (AGDLP):

  • Maak GL_IT (Global Security) aan in OU=Groups
  • Maak DL_IT (Domain Local Security) aan in OU=Groups
  • Voeg Lars, Fatima en Thomas toe als member van GL_IT
  • Voeg GL_IT toe als member van DL_IT

Helpdesk Delegation
Taak 08
Thomas — helpdesk rechten via delegation
config
›

Thomas Jansen bemant de helpdesk en moet wachtwoorden kunnen resetten en accounts kunnen unlocken voor alle domeingebruikers. Hij mag geen lid worden van een ingebouwde standaard security groep.

Aanpak via delegation met een aparte groep:

  • Via PowerShell:

    New-ADGroup -Name "GL_Helpdesk" -GroupScope Global -GroupCategory Security -Path "OU=Groups,DC=pxldigital,DC=local" Add-ADGroupMember -Identity "GL_Helpdesk" -Members "thomas.jansen"
    Maak een nieuwe groep aan in OU=Groups: GL_Helpdesk (Global Security)
  • Voeg Thomas toe als member van GL_Helpdesk
  • ADUC → rechtsklik op pxldigital.local → Delegate Control
  • Voeg GL_Helpdesk toe → kies:
  • Reset user passwords and force password change at next logon
  • Read all user information

Voor account unlock: kies "Create a custom task" → User objects → vink Write lockoutTime aan.

⚠ Let op — Delegeer op domeinniveau zodat Thomas rechten heeft voor alle users in alle OUs.

Service Account & Domain Join
Taak 10
Service account aanmaken voor imaging + WINADV-PC2 joinen
configsecurity
›

De imaging-tool heeft een service account nodig met enkel het recht om computers aan het domein te joinen — niet meer. Het account mag nergens interactief aanmelden.

Service account aanmaken:

  • Via PowerShell:

    New-ADUser -Name "svc_domainjoin" -SamAccountName "svc_domainjoin" ` -Path "OU=IT,OU=Users,DC=pxldigital,DC=local" ` -AccountPassword (ConvertTo-SecureString "P@ssw0rd!2025" -AsPlainText -Force) ` -PasswordNeverExpires $true -Enabled $true
    Maak gebruiker aan: svc_domainjoin — wachtwoord complex, "Password never expires"

Custom delegation op OU Computers:

  • ADUC → rechtsklik op OU=Computers → Delegate Control → voeg svc_domainjoin toe
  • "Create a custom task" → Computer objects → vink Create selected objects in this folder aan

GPO om interactief aanmelden te blokkeren:

  • Maak GPO aan: GPO_ServiceAccount_Restrictions → koppel aan het domein
  • Computer Configuration → Policies → Windows Settings → Security Settings → Local Policies → User Rights Assignment
  • Voeg svc_domainjoin toe aan:
SettingEffect
Deny log on locallyGeen interactief inloggen
Deny log on through Remote Desktop ServicesGeen RDP-toegang
Deny access to this computer from the networkGeen netwerktoegang

WINADV-PC2 joinen via het service account:

  • Installeer nieuwe Windows 11 VM met naam WINADV-PC2
  • Join aan pxldigital.local met credentials van svc_domainjoin
  • Ga op DC1 naar Windows Security Event Log → zoek event ID 4741
  • Controleer of het event verwijst naar WINADV-PC2
ℹ Event ID 4741 — "A computer account was created" — wordt gelogd op de DC die het computerobject aanmaakte, met vermelding van wie het aanmaakte (svc_domainjoin).

Fatima moet GPO's kunnen aanmaken en linken op domeinniveau. Dit zijn twee aparte permissies.

Groep aanmaken:

  • GPMC → rechtsklik op pxldigital.local → Delegate
  • Voeg GL_GPO_Managers toe → permissie: Link GPOs

GPO's mogen aanmaken:

  • GPMC → klik op map Group Policy Objects → tabblad Delegation → Add
  • Voeg GL_GPO_Managers toe → permissie: Edit settings, delete, modify security

Theorie 12
Delegation en Least Privilege begrijpen
theorie
›

Delegatie laat toe om specifieke beheertaken te geven aan gebruikers of groepen, zonder hen volledige Domain Admin-rechten te geven. Dit is de praktische toepassing van het principe van least privilege.

Least PrivilegeGeef elke gebruiker of service enkel de minimale rechten die nodig zijn voor hun taak. Meer rechten = groter aanvalsoppervlak bij een compromis.
ScenarioOplossing
Helpdesk reset wachtwoordenDelegation op domein: Reset passwords
IT-admin logt in op DCDL-groep toevoegen aan GPO User Rights
Imaging-tool joint computersService account met custom delegation op Computers OU
Medewerker maakt GPOs aanGroep toevoegen aan GPMC Delegation tabblad
⚠ Delegeer altijd aan een groep — nooit aan een individuele gebruiker. Zo kun je later mensen toevoegen zonder de delegation opnieuw in te stellen.
Theorie 13
Service accounts en security best practices
theoriesecurity
›

Een service account is een gebruikersaccount dat niet door een mens wordt gebruikt, maar door een applicatie of geautomatiseerd proces.

Best practiceWaarom
Complexe wachtwoorden, nooit verlopenServices crashen bij verlopen wachtwoord
Interactief aanmelden blokkerenVoorkomt misbruik als credentials lekken
Minimale rechten via delegationLeast privilege — service doet enkel wat nodig is
Aparte OU voor service accountsDuidelijk onderscheid, makkelijker te beheren
Naam duidelijk prefixen (svc_)Direct herkenbaar als service account in logs
Event ID 4741Elke keer dat een computerobject wordt aangemaakt in AD, logt Windows dit event op de betrokken DC. Het bevat wie het aanmaakte en voor welke computer — essentieel voor audit en troubleshooting.
