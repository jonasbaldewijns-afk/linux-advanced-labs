Theorie
Theorie 02
HSRP: hoe werkt gateway-redundantie?
theorie
›

Stel: je hebt één router als default gateway. Als die uitvalt, heeft niemand meer internet. HSRP lost dit op met een virtueel IP-adres dat eigendom is van de groep, niet van één router.

BegripUitleg
Virtual IPHet IP dat clients als gateway gebruiken
Active routerVerwerkt al het verkeer voor het virtuele IP
Standby routerLuistert naar hello-berichten, neemt over bij uitval
PriorityHoger getal = active router (default 100)
PreemptLaat de hogere router de active-rol terugpakken na herstel

IP-schema voor dit lab:

ApparaatInterfaceIP
R1 (active)Gi0/0192.168.10.2/24
R2 (standby)Gi0/0192.168.10.3/24
HSRP Virtual IP—192.168.10.1/24 ← dit gebruiken clients
R1-R2 WANGi0/110.0.0.1/30 — 10.0.0.2/30
Theorie 03
Rapid PVST+ en Spanning Tree
theorie
›

STP voorkomt lussen in een geschakeld netwerk. Zonder STP zorgen redundante links voor een broadcast storm die het netwerk platgooit.

STP-versieConvergentieStatus
802.1D (classic STP)30–50 secVerouderd, traag
802.1w (RSTP)1–2 secSnel, één instantie
Rapid PVST+1–2 secCisco — per VLAN, gebruik dit
Root Bridge kiezenDe switch met de laagste Bridge ID (= priority + MAC-adres) wordt Root Bridge. Kies bewust: spanning-tree vlan 10 priority 4096 (stap van 4096, default = 32768). Lage priority = meer kans op root bridge.

Taak 05
HSRP configureren (active/standby)
cisco iosconfig
›

Beide routers gebruiken hetzelfde virtuele IP (192.168.10.1). De router met de hoogste priority wordt actief.

! Op R1 — wordt de ACTIVE router (priority 110 > 100) interface GigabitEthernet0/0 standby version 2 standby 1 ip 192.168.10.1 standby 1 priority 110 standby 1 preempt exit ! Op R2 — wordt de STANDBY router (default priority 100) interface GigabitEthernet0/0 standby version 2 standby 1 ip 192.168.10.1 standby 1 priority 90 standby 1 preempt exit
Waarom preempt?Zonder preempt blijft R2 actief ook nadat R1 hersteld is van een crash. Met preempt pakt R1 (hogere priority) de active-rol automatisch terug.
✓ Verificatieshow standby brief op beide routers: R1 toont "Active", R2 toont "Standby"
