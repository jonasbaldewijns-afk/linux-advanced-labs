Theorie · RAID
Theorie 01
RAID-niveaus begrijpen
theorie
›

RAID staat voor Redundant Array of Independent Disks. Het combineert meerdere schijven voor redundantie en/of performance.

Drie basistechnieken:

  • Striping: data verspreid over schijven → sneller lezen/schrijven
  • Mirroring: data gespiegeld op meerdere schijven → redundantie
  • Parity: wiskundige foutcorrectie → 1 schijf mag falen zonder dataverlies
TypeMin. schijvenTechniekRedundantieGebruik
RAID 02StripingGeen — alles verloren bij failureSnelheid, geen kritische data
RAID 12MirroringJa — 1 schijf mag falenKritische data, OS-schijven
RAID 53Striping + ParityJa — 1 schijf mag falenBalans tussen snelheid en veiligheid
Spanned2Spanning (geen RAID)GeenCapaciteit samenvoegen, geen veiligheid
Software RAID vs Hardware RAIDWindows Server gebruikt software RAID (via Schijfbeheer of Storage Spaces). Dit gebruikt CPU-kracht. Hardware RAID heeft een aparte RAID-controller en is transparant voor het OS.
⚠ Let op — RAID is geen backup. Een schijf mag falen, maar brand, ransomware of meerdere gelijktijdige failures betekenen nog steeds dataverlies.
RAID aanmaken
Taak 02
RAID-volumes aanmaken via Schijfbeheer
installatieconfig
›

Voeg virtuele schijven toe in VMware en maak de gevraagde RAID-volumes aan via Windows Schijfbeheer. Alle volumes gebruiken NTFS als bestandssysteem.

Schijven toevoegen in VMware:

  • VM → Settings → Add → Hard Disk → SCSI → 5 GB
  • Herhaal tot je genoeg schijven hebt voor alle volumes
  • In Windows: Start → Schijfbeheer → initialiseer nieuwe schijven als GPT
  • Rechtsklik op elke nieuwe schijf → Convert to Dynamic Disk (vereist voor software RAID)

Volume 1 — RAID 1 (Mirror)

  • 2 schijven van 5 GB
  • Rechtsklik op een schijf → New Mirrored Volume
  • Voeg de tweede schijf toe → stationsletter: Z → volumenaam: DataRaid1

Volume 2 — RAID 0 (Stripe)

  • 2 schijven van 5 GB
  • Rechtsklik → New Striped Volume
  • Stationsletter: Y → volumenaam: DataRaid0

Volume 3 — RAID 5 (Stripe + Parity)

  • 3 schijven van 5 GB
  • Rechtsklik → New RAID-5 Volume
  • Stationsletter: X → volumenaam: DataRaid5

Volume 4 — Spanned volume

  • 2 schijven van 5 GB — data verspreid over beide schijven als één grote schijf, zonder redundantie
  • Rechtsklik → New Spanned Volume
  • Stationsletter: Q → volumenaam: DataDisks
✔ VerificatieIn Schijfbeheer zijn alle 4 volumes zichtbaar met status Healthy. Elk volume heeft de juiste stationsletter en naam.

Partities weergeven via PowerShell:

Open PowerShell en toon alle volumes met één commando:

Get-Volume

Dit toont alle volumes met stationsletter, naam, bestandssysteem en grootte. Controleer of alle 4 volumes zichtbaar zijn.

Theorie 03
NTFS-permissies en SMB-shares begrijpen
theorie
›

Bij netwerkmappen spelen twee lagen een rol:

LaagWat regelt het?Instelling via
NTFS-permissiesLokale bestandstoegang (lezen, schrijven, uitvoeren...)Properties → Security
Share-permissiesNetwerktoegang (wie mag überhaupt verbinden)Properties → Sharing → Advanced Sharing
Gecombineerde rechtenBij netwerktoegang gelden beide lagen tegelijk. Het meest restrictieve recht wint altijd. Best practice: Share-permissie = Everyone Full Control, alles beheren via NTFS.
NTFS-rechtWat mag je?
Full ControlAlles inclusief rechten wijzigen
ModifyLezen, schrijven, verwijderen
Read & ExecuteBestanden openen en uitvoeren
ReadAlleen lezen
WriteAanmaken en bewerken
ℹ AGDLP — Geef nooit rechtstreeks rechten aan individuele gebruikers. Gebruik altijd: Account → Global Group → Domain Local Group → Permissie op map.
FileShare
Taak 04
FileShare aanmaken met Students-map en drive mapping
config
›

Maak de hoofdshare aan op de server en voeg een map Students toe met de juiste rechten.

Share aanmaken:

  • Maak een map aan op de server, bijv. C:\FileShare
  • Rechtsklik → Properties → Sharing → Advanced Sharing

  • Via PowerShell — share aanmaken:

    New-Item -Path "C:\FileShare" -ItemType Directory -Force New-SmbShare -Name "FileShare" -Path "C:\FileShare" -FullAccess "Everyone"
    Vink "Share this folder" aan → Share name: FileShare
  • Permissions: Everyone → Full Control (rechten beheer je via NTFS)

Map Students aanmaken met NTFS-rechten:

  • Maak C:\FileShare\Students aan
  • Rechtsklik → Properties → Security → Edit
  • Verwijder eventuele te brede rechten (bijv. Users Write)
  • Voeg toe: DL_All_Students → Read
  • Voeg toe: Administrators → Full Control

  • Via PowerShell — NTFS-rechten Students-map:

    New-Item -Path "C:\FileShare\Students" -ItemType Directory -Force icacls "C:\FileShare\Students" /inheritance:d icacls "C:\FileShare\Students" /grant "PXLDIGITAL\DL_All_Students:(OI)(CI)R" icacls "C:\FileShare\Students" /grant "BUILTIN\Administrators:(OI)(CI)F"
    Studenten mogen enkel lezen, niet schrijven

Drive mapping voor een student (manueel):

  • Log in op de client als een domeingebruiker (student)
  • Open Verkenner → This PC → Map network drive
  • Letter: Y → pad: \\WINADV-DC1XX\FileShare\Students
  • Vink "Reconnect at sign-in" aan → Finish
✔ VerificatieDe student ziet schijf Y: in Verkenner. Proberen te schrijven geeft een foutmelding — enkel lezen is toegestaan.
Taak 05
Klasfolders aanmaken met rechten per klas
config
›

Maak voor elke SNE-klas een aparte map aan binnen de FileShare. De rechten zijn voor alle klassen identiek qua structuur:

GroepNTFS-recht
Klas zelf (DL_1SNEx)Read & Execute
DL_All_LectorsModify (lezen + schrijven)
AdministratorsFull Control

Aanmaken:

  • Maak mappen aan: C:\FileShare\1SNEa, 1SNEb, 1SNEc, 1SNEd, 1SNEe

  • Via PowerShell — klasfolders aanmaken met rechten:

    foreach ($klas in "1SNEa","1SNEb","1SNEc","1SNEd","1SNEe") { $pad = "C:\FileShare\$klas" New-Item -Path $pad -ItemType Directory -Force icacls $pad /inheritance:d icacls $pad /grant "PXLDIGITAL\DL_$klas:(OI)(CI)(RX)" icacls $pad /grant "PXLDIGITAL\DL_All_Lectors:(OI)(CI)M" icacls $pad /grant "BUILTIN\Administrators:(OI)(CI)F" }
    Stel per map de NTFS-rechten in zoals hierboven
  • Gebruik de DL_ groepen — geef nooit rechtstreeks rechten aan individuele gebruikers of GL_ groepen
  • Schakel overerving van de bovenliggende map uit indien nodig: Properties → Security → Advanced → Disable inheritance
ℹ Efficiënt werken — Stel rechten in op de eerste map en gebruik xcopy of kopieer de Security-instellingen via "Advanced" → eigen invoer per map. Of gebruik PowerShell: Get-Acl / Set-Acl om rechten te kopiëren.

Er is een aparte map nodig voor de studentenraad. De vertegenwoordigers per klas krijgen lees- en schrijfrechten, alle studenten krijgen leesrechten. Rechten worden via AGDLP ingesteld — nooit rechtstreeks aan gebruikers.

AGDLP-aanpak:

  • Maak een nieuwe Global Group aan: GL_Studentenraad in OU=Groups
  • Voeg de 5 vertegenwoordigers toe als member van GL_Studentenraad
  • Maak een Domain Local Group aan: DL_Studentenraad
  • Voeg GL_Studentenraad toe als member van DL_Studentenraad
  • Maak de map aan: C:\FileShare\Studentenraad
  • NTFS-rechten instellen:
GroepNTFS-recht
DL_StudentenraadModify (lezen + schrijven)
DL_All_StudentsRead
AdministratorsFull Control
⚠ Let op — Voeg nooit individuele gebruikers toe aan NTFS-rechten. Altijd via de DL-groep. Dit is de kern van AGDLP.
Taak 07
Aparte share voor coördinatoren op RAID 1
config
›

De coördinatoren Liesbeth Peeters en Tom De Wilde hebben een eigen gedeelde map nodig. Deze mag niet in de bestaande FileShare-share staan. De map moet opgeslagen worden op het RAID 1-volume (Z:) voor redundantie.

AGDLP-aanpak:

  • Maak een Global Group aan: GL_Coordinatoren in OU=Groups
  • Voeg toe als member: Liesbeth Peeters, Tom De Wilde
  • Maak een Domain Local Group aan: DL_Coordinatoren
  • Voeg GL_Coordinatoren toe als member van DL_Coordinatoren

Map en share aanmaken op RAID 1:

  • Maak de map aan op het RAID 1-volume: Z:\CoordShare
  • NTFS-rechten: DL_Coordinatoren → Modify, Administrators → Full Control
  • Rechtsklik → Properties → Sharing → Advanced Sharing

  • Via PowerShell — map, NTFS en share:

    New-Item -Path "Z:\CoordShare" -ItemType Directory -Force icacls "Z:\CoordShare" /inheritance:d icacls "Z:\CoordShare" /grant "PXLDIGITAL\DL_Coordinatoren:(OI)(CI)M" icacls "Z:\CoordShare" /grant "BUILTIN\Administrators:(OI)(CI)F" New-SmbShare -Name "CoordShare" -Path "Z:\CoordShare" -FullAccess "PXLDIGITAL\DL_Coordinatoren"
    Share name: CoordShare
  • Share-permissie: DL_Coordinatoren → Full Control (NTFS doet de echte beperking)
✔ VerificatieLiesbeth Peeters en Tom De Wilde kunnen verbinden via \\WINADV-DC1XX\CoordShare en bestanden lezen en schrijven. Andere gebruikers krijgen toegang geweigerd.
ℹ Waarom RAID 1? — De data van de coördinatoren is kritisch. RAID 1 spiegelt de data op twee schijven, zodat bij uitval van één schijf geen data verloren gaat.
