RAID
Theorie 01
RAID-niveaus begrijpen
theorie
›

RAID staat voor Redundant Array of Independent Disks. Het combineert meerdere schijven voor redundantie en/of performance.

Drie basistechnieken:

  • Striping: data verspreid over schijven → sneller
  • Mirroring: data gespiegeld → redundantie
  • Parity: foutcorrectie via wiskundige berekening
RAIDMin. schijvenTechniekVerlies bij failurePerformance
RAID 02StripingAlles — geen redundantieSnel
RAID 12Mirroring0% data — 1 schijf mag falenNormaal
RAID 53Striping + Parity0% data — 1 schijf mag falenGoed
RAID 64Striping + Parity0% data — 2 schijven mogen falenGoed
RAID 104Mirroring + StripingAfhankelijk van welke schijfSnel
⚠ Let op — Software RAID (via Windows Schijfbeheer) gebruikt CPU-tijd. Hardware RAID heeft een aparte controller.
Taak 02
RAID aanmaken in Windows Server (Schijfbeheer)
installatieconfig
›

Voeg eerst extra virtuele schijven toe in VMware, dan maak je RAID aan in Windows.

Schijven toevoegen in VMware:

  • VM → Settings → Add → Hard Disk
  • Herhaal voor 2 of meer extra schijven (SCSI, 10 GB elk)

RAID aanmaken in Windows:

  • Start → Zoek "Disk Management" (Schijfbeheer)
  • Initialiseer de nieuwe schijven (GPT)
  • Rechtsklik op een schijf → New Mirrored Volume (voor RAID 1)
  • Of: New Striped Volume (RAID 0) / New RAID-5 Volume
  • Voeg de gewenste schijven toe in de wizard
  • Formatteer als NTFS, wijs een stationsletter toe
✔ VerificatieIn Schijfbeheer zie je het RAID-volume als één stationsletter. Status moet "Healthy" zijn.

Theorie 03
NTFS-machtigingen en ACLs begrijpen
theorie
›

NTFS-machtigingen werken op bestand- en mapniveau via Access Control Lists (ACLs).

MachtigingWat mag je?
Full ControlAlles: lezen, schrijven, verwijderen, rechten wijzigen
ModifyLezen, schrijven, verwijderen — maar geen rechten wijzigen
Read & ExecuteBestanden openen en uitvoeren
List Folder ContentsInhoud van map bekijken
ReadBestanden lezen
WriteBestanden aanmaken en bewerken
ACLElke map/bestand heeft een Access Control List met ACEs (Access Control Entries) per gebruiker/groep. Windows controleert deze bij toegang.

Overerving (Inheritance): Submappen erven standaard de rechten van de bovenliggende map. Je kunt overerving uitschakelen per object.

Taak 04
NTFS-rechten instellen op een map
config
›

Maak een map aan en stel NTFS-rechten in via de GUI.

  • Maak de map C:\Data\Klassen aan
  • Rechtsklik → Properties → tabblad Security → Edit
  • Voeg de groep DL_FileShare_Lezen toe → kies: Read & Execute
  • Klik OK → Apply
⚠ Let op — Verwijder niet de bestaande SYSTEM en Administrators rechten — daarmee kun je jezelf buitensluiten.
ℹ Info — Wil je overerving uitschakelen? Properties → Security → Advanced → Disable inheritance.

Theorie 05
SMB en share-permissies begrijpen
theorie
›

SMB (Server Message Block) is het protocol voor netwerkmappen in Windows. Er zijn twee toegangslagen:

LaagWat doet het?Instelling via
Share-permissiesNetwerktoegang regelen (wie mag verbinden)Sharing-tabblad in Properties
NTFS-permissiesLokale bestandstoegang regelen (wat mag je doen)Security-tabblad in Properties
Gecombineerde rechtenBij toegang via het netwerk gelden beide lagen. Het meest restrictieve recht wint. Best practice: Share-permissie = Everyone/Full Control, alles regelen via NTFS.
⚠ Let op — SMBv1 is verouderd en onveilig — nooit gebruiken. Zorg dat SMBv2/v3 actief is.
Taak 06
Een SMB-share aanmaken
config
›

Deel de map C:\Data\Klassen via het netwerk.

Via Windows Verkenner:

  • Rechtsklik op de map → Properties → tabblad Sharing
  • Klik "Advanced Sharing" → vink "Share this folder" aan
  • Share name: Klassen
  • Klik "Permissions" → verwijder Everyone → voeg DL_FileShare_Lezen toe met Read
  • OK → Apply → OK
✔ VerificatieOpen Verkenner op de client: \\WINADV-DC1\Klassen — je moet de map kunnen zien.

⚠ Let op — Administratieve shares zijn standaard actief. Ze uitschakelen vereist registry-aanpassing en is niet aangeraden in een domein.
