Theorie 01
Hybrid identiteitsmodel begrijpen
theorie
›

Een hybride identiteitsmodel combineert een on-premises Active Directory met Microsoft Entra ID (vroeger Azure AD). Gebruikers hebben één identiteit die zowel lokaal als in de cloud werkt.

Entra ConnectDe tool die AD-objecten (gebruikers, groepen) synchroniseert naar Entra ID. Wijzigingen in AD worden automatisch doorgevoerd naar de cloud.
BegripWat doet het?
Entra ID (Azure AD)Cloud-identiteitsprovider van Microsoft — authenticatie voor M365, Teams, enz.
Entra ConnectSynchroniseert on-premises AD naar Entra ID
Hybrid JoinComputers zijn tegelijk lid van on-premises AD én geregistreerd in Entra/Intune
IntuneMDM-platform (Mobile Device Management) voor cloud-gebaseerd apparaatbeheer
LAPSLocal Administrator Password Solution — automatisch beheer van lokale admin-wachtwoorden
ℹ GPO vs. Intune — GPO werkt enkel op apparaten die rechtstreeks met het domein verbonden zijn. Intune werkt overal via het internet — ideaal voor thuiswerkers en laptops buiten het schoolnetwerk.
Entra Connect
Taak 02
WINADV-EC aanmaken en Entra Connect Agent installeren
installatieconfig
›

Maak een nieuwe Windows Server 2025 VM aan speciaal voor Entra Connect. Deze server moet internettoegang hebben om te communiceren met Microsoft 365.

VM aanmaken en configureren:

  • Naam: WINADV-EC
  • Voeg een tweede netwerkinterface toe in VMware ingesteld op NAT — dit simuleert internettoegang
  • Eerste NIC: intern netwerk (verbinding met DC)
  • Tweede NIC: NAT (verbinding met internet via M365)
  • Voeg de server toe aan het domein pxldigital.local

Entra Connect Agent installeren:

  • Download de Microsoft Entra Connect installer via de Microsoft-downloadpagina of Entra Admin Center
  • Voer de installer uit op WINADV-EC
  • Kies: Express settings of Custom (afhankelijk van je situatie)
  • Meld aan met je M365 Global Admin-account
  • Selecteer de te synchroniseren OUs
  • Start de initiële synchronisatie
✔ VerificatieIn Entra Admin Center (entra.microsoft.com) zijn de AD-gebruikers en -groepen zichtbaar. Controleer ook de Audit Logs voor bevestiging van de synchronisatie.
Taak 03
Nieuwe studenten aanmaken + sync + licentiegroep
config
›

Er komt in elke klas een nieuwe student bij. Maak ze aan in AD — ze worden via Entra Connect automatisch gesynchroniseerd naar Entra.

KlasNaamLogon name
1SNEaDaan Vermeulend.vermeulen
1SNEbLotte Van Heckel.van.hecke
1SNEcNathan De Pauwn.de.pauw
1SNEdHanne Coppensh.coppens
1SNEeJasper Moensj.moens

Via PowerShell:

$pw = ConvertTo-SecureString "TestTest2025" -AsPlainText -Force $base = "OU=Studenten,DC=pxldigital,DC=local" @( @{Name="Daan Vermeulen"; Sam="d.vermeulen"; OU="1SNEa"}, @{Name="Lotte Van Hecke"; Sam="l.van.hecke"; OU="1SNEb"}, @{Name="Nathan De Pauw"; Sam="n.de.pauw"; OU="1SNEc"}, @{Name="Hanne Coppens"; Sam="h.coppens"; OU="1SNEd"}, @{Name="Jasper Moens"; Sam="j.moens"; OU="1SNEe"} ) | ForEach-Object { New-ADUser -Name $_.Name -SamAccountName $_.Sam ` -Path "OU=$($_.OU),$base" ` -AccountPassword $pw -Enabled $true }
Maak elke student aan in de juiste sub-OU van OU=Studenten, dan in de juiste GL-klasgroep. Na de volgende sync-cyclus (max. 30 min, of forceer via Start-ADSyncSyncCycle op WINADV-EC) zijn ze zichtbaar in Entra.

Start-ADSyncSyncCycle -PolicyType Delta

CG_Demo_E5 — licentiegroep aanmaken:

  • Maak in Entra Admin Center een nieuwe security groep aan: CG_Demo_E5
  • Ga naar Microsoft 365 Admin Center → Billing → Licenses
  • Selecteer de E5-licentie → Assign licenses → kies de groep CG_Demo_E5
  • Alle members van deze groep krijgen automatisch een E5-licentie toegewezen
ℹ Group-based licensing — Door licenties aan een groep toe te wijzen in plaats van aan individuele gebruikers, beheer je licenties automatisch. User erbij = licentie erbij. User weg = licentie vrijgegeven.
Hybrid Join & Intune
Taak 04
CG_Hybrid_Devices + automatische Hybrid Join registratie
config
›

Let op: verwijder eerst alle bestaande device groepen in Entra/Intune om conflicten te vermijden.

Dynamische device groep aanmaken:

  • Maak in Entra Admin Center een nieuwe groep aan: CG_Hybrid_Devices
  • Membership type: Dynamic Device
  • Dynamic rule: toestellen waarvan de naam begint met WINADV
  • Rule syntax: (device.displayName -startsWith "WINADV")

Hybrid Join configureren (automatische Intune-registratie):

  • Volg de handleiding "Hybrid Join - Entra + MDM" uit de cursus
  • Alle huidige en toekomstige computers die aan het domein zijn toegevoegd, registreren zich automatisch in Entra en Intune
  • Voer op de client dsregcmd /status uit ter verificatie:
dsregcmd /status

In de output moet je zien: AzureAdJoined: YES en DomainJoined: YES. Dit bevestigt dat het toestel zowel on-premises als in Entra geregistreerd is.

✔ VerificatieIn Intune Admin Center (intune.microsoft.com) → Devices: de client verschijnt. In Entra: het apparaat is zichtbaar in de groep CG_Hybrid_Devices.
Intune Policies
Taak 05
Intune policies: achtergrond, Control Panel, Task Manager
config
›

Vervang GPO-restricties door Intune policies. Stap 1: unlink de GPO in GPMC zodat die niet meer actief is. Stap 2: maak de equivalente Intune policy aan.

Alle Intune policies maak je aan via: Intune Admin Center → Devices → Configuration → Create policy → Windows 10 and later → Settings Catalog

1. Bureaublad achtergrond — CG_Hybrid_Devices

  • Geen GPO te unlinken — dit is een nieuwe Intune-only policy
  • Stel een achtergrond in die anders is dan de GPO-achtergrond (zodat je het verschil ziet)
  • Zoekterm in Settings Catalog: Desktop Image URL of Personalization
  • Toewijzen aan groep: CG_Hybrid_Devices

2. Control Panel verbieden — 1SNEe

  • Unlink in GPMC de GPO GPO_1SNEe_NoControlPanel van OU=1SNEe
  • Test op client: Control Panel is terug toegankelijk (bevestigt dat GPO weg is)
  • Maak nieuwe Entra-groep aan: CG_1SNEe — voeg de 1SNEe-studenten toe
  • Nieuwe Intune policy → Settings Catalog → zoek: Prohibit access to Control Panel
  • Toewijzen aan groep: CG_1SNEe

3. Task Manager verbieden — 1SNEa

  • Unlink in GPMC de GPO GPO_1SNEa_NoTaskManager van OU=1SNEa
  • Maak nieuwe Entra-groep aan: CG_1SNEa — voeg de 1SNEa-studenten toe
  • Nieuwe Intune policy → Settings Catalog → zoek: Remove Task Manager
  • Toewijzen aan groep: CG_1SNEa
⚠ Let op — Intune policies worden toegepast op gebruikers of apparaten, niet op OUs. Zorg dat de juiste studenten in de CG_-groepen zitten voordat je de policy toewijst.
Taak 06
Intune policies: C-schijf, CMD/PS en regedit
config
›

4. C-schijf verbieden — 1SNEb

  • Unlink in GPMC de GPO GPO_1SNEb_NoC_Drive van OU=1SNEb
  • Maak nieuwe Entra-groep aan: CG_1SNEb — voeg de 1SNEb-studenten toe
  • Nieuwe Intune policy → Settings Catalog → zoek: Prevent access to drives from My Computer
  • Toewijzen aan groep: CG_1SNEb

5. CMD en PowerShell verbieden — alle studenten

  • Unlink in GPMC de GPO GPO_Studenten_NoShell van OU=Studenten
  • Test op client: CMD en PowerShell zijn terug toegankelijk
  • Nieuwe Intune policy → Settings Catalog → zoek: Prevent access to the command prompt
  • Voeg ook toe: Don't run specified Windows applications → voeg powershell.exe toe
  • Toewijzen aan bestaande groep: DL_All_Students

6. Regedit verbieden — alle studenten

  • Unlink in GPMC de regedit-GPO van OU=Studenten
  • Nieuwe Intune policy → Settings Catalog → zoek: Prevent access to registry editing tools
  • Toewijzen aan groep: DL_All_Students
ℹ DL_All_Students in Intune? — Intune werkt met Entra-groepen. De DL_All_Students groep wordt via Entra Connect gesynchroniseerd vanuit AD. Zorg dat ze zichtbaar is in Entra Admin Center vóór je de policy toewijst.
C$ Toegang & LAPS
Taak 07
IT-medewerkers C$ toegang + Entra LAPS configureren
configsecurity
›

IT-medewerkers toegang geven tot de verborgen C$-share:

Standaard hebben enkel Domain Admins toegang tot de C$-share van een computer. IT-medewerkers hebben die toegang ook nodig. De oplossing is hen toe te voegen aan de lokale Administrators-groep op de clientcomputers, via GPO.

  • Maak een nieuwe GPO aan of gebruik de bestaande Firewall-GPO
  • Computer Configuration → Preferences → Control Panel Settings → Local Users and Groups
  • Rechtsklik → New → Local Group
  • Group name: Administrators (built-in) → Action: Update
  • Voeg DL_IT toe als member
  • Koppel de GPO aan de OU waar de clientcomputers staan
✔ VerificatieLog in als IT-medewerker op computer 1 en probeer via Verkenner \\WINADV-PC1\C$ te openen. Dit moet lukken.

Entra LAPS configureren op CG_Hybrid_Devices:

LAPS (Local Administrator Password Solution) genereert automatisch een uniek, roterend wachtwoord voor het lokale Administrator-account op elk apparaat.

  • Volg de "Entra LAPS"-handleiding uit de cursus
  • Ga in Intune Admin Center naar: Endpoint Security → Account protection → Create policy → Local admin password solution (Windows LAPS)
  • Toewijzen aan groep: CG_Hybrid_Devices
✔ VerificatieIn Intune Admin Center → Devices → selecteer een toestel uit CG_Hybrid_Devices → tabblad Local admin password: het LAPS-wachtwoord is zichtbaar en heeft een rotatieschema.
Waarom LAPS?Zonder LAPS gebruiken beheerders overal hetzelfde lokale admin-wachtwoord. Als dat uitlekt, is elke computer kwetsbaar. LAPS geeft elk toestel een uniek wachtwoord dat automatisch roteert — een gecompromitteerd wachtwoord geeft enkel toegang tot dat ene toestel.
