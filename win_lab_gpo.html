Theorie 01
GPO-concept, LSDOU en troubleshooting
theorie
›

Group Policy Objects (GPOs) zijn containers voor beleidsinstellingen die automatisch worden toegepast op gebruikers en computers in Active Directory.

LSDOU — verwerkingsvolgordeGPOs worden verwerkt in deze volgorde: Local → Site → Domein → OU. Later toegepaste GPOs overschrijven eerdere — een OU-policy wint dus altijd van een domein-policy.
NiveauBeschrijvingVoorbeeld
LocalOp de computer zelfLokale Group Policy Editor
SiteAD-site (geografisch)Beleid per campus
DomainHeel het domeinWachtwoordbeleid, lockout
OUSpecifieke containerRestricties per klas

GPO aanmaken — basisstappen:

  • Open Group Policy Management Console (GPMC) via Server Manager of zoek "Group Policy Management"
  • Rechtsklik op "Group Policy Objects" → New → geef een duidelijke naam
  • Rechtsklik op de GPO → Edit → navigeer naar de gewenste instelling
  • Rechtsklik op de juiste OU → "Link an Existing GPO" → selecteer de GPO

Troubleshooting:

gpupdate /force

Forceert onmiddellijke verwerking op de client (normaal duurt dit max. 90 min). Voer dit uit als domeingebruiker op de client.

gpresult /R

Toont welke GPOs effectief zijn toegepast op de huidige gebruiker en computer (RSOP = Resultant Set of Policy). Handig bij conflicten tussen GPOs.

gpresult /H C:\rapport.html

Genereert een volledig HTML-rapport van alle toegepaste GPOs. Open in de browser voor een overzicht.

Drive Mapping
Taak 02
FileShare automatisch mappen voor alle domeingebruikers
config
›

Zorg dat de FileShare-netwerkmap automatisch wordt gekoppeld op stationsletter X: voor alle gebruikers van het domein via GPO Drive Maps.

GPO aanmaken en configureren:

  • Maak een nieuwe GPO aan: GPO_DriveMap_FileShare
  • Edit → User Configuration → Preferences → Windows Settings → Drive Maps
  • Rechtsklik → New → Mapped Drive
  • Action: Create
  • Location: \\WINADV-DC1XX\FileShare
  • Label as: FileShare
  • Drive Letter: X
  • Vink aan: Reconnect

GPO koppelen:

  • Via PowerShell — GPO aanmaken en linken:

    New-GPO -Name "GPO_DriveMap_FileShare" New-GPLink -Name "GPO_DriveMap_FileShare" -Target "DC=pxldigital,DC=local"

    De Drive Maps-instelling zelf is een Preference en wordt het makkelijkst via de GUI geconfigureerd. PowerShell kan GPO-instellingen inspecteren via:

    Get-GPOReport -Name "GPO_DriveMap_FileShare" -ReportType Html -Path "C:\gpo-report.html"
    Link de GPO aan het domein (pxldigital.local) zodat alle domeingebruikers hem ontvangen

User profiel aanpassen:

  • In ADUC: open de properties van een gebruiker → tabblad Profile
  • Verwijder eventuele bestaande "Connect to"-instellingen zodat de GPO niet conflicteert
✔ VerificatieLog in op de client als domeingebruiker en voer gpupdate /force uit. Schijf X: verschijnt in Verkenner.
Administrative Templates — Restricties
Taak 03
Restricties instellen per klas via Administrative Templates
config
›

Maak voor elke klas een aparte GPO aan en koppel die aan de juiste sub-OU van OU=Studenten. Alle instellingen zitten onder User Configuration → Policies → Administrative Templates.

1. Control Panel blokkeren — 1SNEe

  • GPO: GPO_1SNEe_NoControlPanel → koppel aan OU=1SNEe
  • Pad: Administrative Templates → Control Panel
  • Instelling: Prohibit access to Control Panel and PC settings → Enabled

2. Task Manager blokkeren — 1SNEa

  • GPO: GPO_1SNEa_NoTaskManager → koppel aan OU=1SNEa
  • Pad: Administrative Templates → System → Ctrl+Alt+Del Options
  • Instelling: Remove Task Manager → Enabled

3. C-schijf blokkeren en verbergen — 1SNEb

  • GPO: GPO_1SNEb_NoC_Drive → koppel aan OU=1SNEb
  • Pad: Administrative Templates → Windows Components → File Explorer
  • Instelling: Prevent access to drives from My Computer → Enabled
  • Selecteer in de dropdown: Restrict C drive only
  • Alle andere gebruikers (andere klassen) krijgen deze policy niet — enkel 1SNEb

4. CMD en PowerShell blokkeren — alle studenten

  • GPO: GPO_Studenten_NoShell → koppel aan OU=Studenten (geldt voor alle sub-OUs)
  • Pad 1: Administrative Templates → System → Prevent access to the command prompt → Enabled
  • Pad 2: Administrative Templates → System → Don't run specified Windows applications → Enabled
  • Voeg toe aan de lijst: powershell.exe en powershell_ise.exe
  • Lectoren vallen niet onder OU=Studenten en worden dus niet geraakt

Via PowerShell — GPOs aanmaken en linken:

New-GPO -Name "GPO_1SNEe_NoControlPanel" New-GPLink -Name "GPO_1SNEe_NoControlPanel" -Target "OU=1SNEe,OU=Studenten,DC=pxldigital,DC=local" New-GPO -Name "GPO_1SNEa_NoTaskManager" New-GPLink -Name "GPO_1SNEa_NoTaskManager" -Target "OU=1SNEa,OU=Studenten,DC=pxldigital,DC=local" New-GPO -Name "GPO_1SNEb_NoC_Drive" New-GPLink -Name "GPO_1SNEb_NoC_Drive" -Target "OU=1SNEb,OU=Studenten,DC=pxldigital,DC=local" New-GPO -Name "GPO_Studenten_NoShell" New-GPLink -Name "GPO_Studenten_NoShell" -Target "OU=Studenten,DC=pxldigital,DC=local"
⚠ Let op — Koppel OU-specifieke GPOs altijd aan de juiste sub-OU, niet aan het volledige domein. Gebruik de Scope-tab in GPMC om te verifiëren welke OUs en gebruikers geraakt worden.
Security Settings
Taak 04
Guest account, Account Lockout en Password Policy
configsecurity
›

De volgende drie instellingen gelden voor het hele domein en worden geconfigureerd in de Default Domain Policy. Bewerk die GPO rechtstreeks — maak geen nieuwe aan.

Open GPMC → pxldigital.local → Default Domain Policy → rechtsklik → Edit.

1. Guest account uitschakelen op alle clients

  • Pad: Computer Configuration → Policies → Windows Settings → Security Settings → Local Policies → Security Options
  • Instelling: Accounts: Guest account status → Disabled

2. Account Lockout Policy

  • Pad: Computer Configuration → Policies → Windows Settings → Security Settings → Account Policies → Account Lockout Policy
InstellingWaardeWaarom

3. Password Policy

  • Pad: Computer Configuration → Policies → Windows Settings → Security Settings → Account Policies → Password Policy
InstellingWaardeWaarom
Enforce password history3 wachtwoordenHergebruik van de laatste 3 wachtwoorden verboden
Maximum password age30 dagenWachtwoord moet elke 30 dagen worden gewijzigd
Minimum password age1 dagVoorkomt dat gebruikers direct terugschakelen naar oud wachtwoord

Zelf Uitzoeken
Taak 05
Registry blokkeren en bureaublad achtergrond instellen
config
›

Deze twee instellingen zoek je zelf op in de GPO-editor. Dit hoort bij het leren navigeren in de ~4000 beschikbare GPO-instellingen.

1. Registry editing tools blokkeren voor alle studenten

  • GPO koppelen aan OU=Studenten
  • Zoek in User Configuration → Policies → Administrative Templates naar een instelling die regedit.exe blokkeert
  • Tip: zoek op "registry" in de zoekbalk van de GPO-editor
  • Schakel de instelling in → test door als student te proberen regedit te openen

2. Bureaublad achtergrond instellen voor studenten én lectoren

  • GPO koppelen aan het domein of aan beide OUs afzonderlijk
  • Zoek in User Configuration → Policies → Administrative Templates naar de instelling voor bureaubladachtergrond (wallpaper)
  • Stel een afbeeldingspad in dat bereikbaar is via het netwerk (bijv. op de FileShare) of lokaal op de client
  • Tip: zoek op "wallpaper" of "desktop background" in de GPO-editor
Waarom zelf opzoeken?In de praktijk zoek je GPO-instellingen op via de zoekfunctie of via de Microsoft documentatie. Uit het hoofd kennen is niet realistisch — weten hoe je het vindt wel.
Firewall via GPO
Taak 06
Firewall rule uitrollen via GPO (SMB-IN poort 445)
configsecurity
›

Administrators hebben toegang nodig tot de verborgen C$-share van clientcomputers. Hiervoor moet poort 445 (SMB) open staan in de Windows Firewall op de clients. Dit rule rol je uit via GPO zodat het automatisch geldt op alle endpoints.

GPO aanmaken:

  • Maak een nieuwe GPO aan: GPO_FW_SMB_IN

  • Via PowerShell — GPO aanmaken en linken:

    New-GPO -Name "GPO_FW_SMB_IN" New-GPLink -Name "GPO_FW_SMB_IN" -Target "DC=pxldigital,DC=local"

    De firewall-regel zelf configureer je via de GUI in de GPO-editor. Je kunt bestaande regels op een client wel inspecteren via:

    Get-NetFirewallRule -DisplayName "*SMB*" | Select-Object DisplayName, Enabled, Direction, Action
    Koppel aan het domein (pxldigital.local) zodat alle computers de regel ontvangen
  • Edit → Computer Configuration → Policies → Windows Settings → Security Settings → Windows Defender Firewall with Advanced Security
  • Rechtsklik op Inbound Rules → New Rule

Rule configureren:

  • Rule type: Port
  • Protocol: TCP
  • Specific local ports: 445
  • Action: Allow the connection
  • Profile: Domain only — enkel actief in het domeinnetwerk
  • Name: SMB-IN-445-Domain
⚠ Let op — Beperk deze rule tot het Domain-profiel. Poort 445 open laten op Public of Private profielen is een beveiligingsrisico.
✔ VerificatieNa gpupdate /force op de client: open Windows Defender Firewall op de client en controleer of de inbound rule zichtbaar is.
