Theorie · Active Directory
Theorie 01
Active Directory en LDAP begrijpen
theorie
›

Active Directory (AD) is het centrale beheersysteem van Microsoft voor een domein. Het slaat alle gebruikers, computers, policies en configuraties op in de database NTDS.dit.

LDAPLightweight Directory Access Protocol — het protocol waarmee clients en diensten gegevens uit AD opvragen. LDAP gebruikt een hiërarchische boomstructuur (Distinguished Names).
TermBetekenis
NTDS.ditDe AD-database — bevat alle domeinobjecten
DCDomain Controller — server die AD host
DNDistinguished Name — volledig pad van een AD-object
OUOrganizational Unit — container voor objecten in AD

Installatie Active Directory
Taak 03
AD DS-rol en DNS-rol installeren
installatie
›

Installeer de Active Directory Domain Services-rol op je WINADV-DC1XX server. DNS wordt automatisch meegeïnstalleerd — dit is vereist.

  • Open Server Manager
  • Manage → Add Roles and Features
  • Role-based installation → Next
  • Selecteer je server → Next
  • Vink aan: Active Directory Domain Services

  • Via PowerShell:

    Install-WindowsFeature AD-Domain-Services -IncludeManagementTools
    In het pop-up: "Add Features" (dit voegt ook DNS Server toe)
  • Next → Next → Install → wacht tot installatie klaar is
Taak 04
Server promoveren tot Domain Controller
config
›

Na de installatie zie je een gele waarschuwing in Server Manager. Klik erop om de promotie-wizard te starten.

  • Kies: Add a new forest
  • Root domain name: pxldigital.local
  • Forest/Domain functional level: Windows Server 2016 of hoger
  • Vink aan: DNS Server, Global Catalog
  • Stel een DSRM-wachtwoord in (Directory Services Restore Mode — bewaar dit!)
  • NetBIOS-naam wordt automatisch: PXLDIGITAL
  • Paths: laat standaard → Next → Install
⚠ Let op — De server herstart automatisch.

Via PowerShell:

Install-ADDSForest ` -DomainName "pxldigital.local" ` -DomainNetbiosName "PXLDIGITAL" ` -InstallDns ` -SafeModeAdministratorPassword (ConvertTo-SecureString "P@ssw0rd!" -AsPlainText -Force) ` -Force
Na herstart log je in met PXLDIGITAL\Administrator.
✔ VerificatieOpen Active Directory Users and Computers (ADUC) — je ziet de domeinstructuur verschijnen.

config

Via PowerShell:

$base = "DC=pxldigital,DC=local" New-ADOrganizationalUnit -Name "Lectoren" -Path $base New-ADOrganizationalUnit -Name "Studenten" -Path $base New-ADOrganizationalUnit -Name "Groups" -Path $base New-ADOrganizationalUnit -Name "Laptops" -Path $base $stud = "OU=Studenten,$base" foreach ($klas in "1SNEa","1SNEb","1SNEc","1SNEd","1SNEe") { New-ADOrganizationalUnit -Name $klas -Path $stud }

Taak 06
Gebruikersaccounts aanmaken
config
›

Maak alle gebruikers aan in de juiste OU. Rechtsklik op de OU → New → User.

Via PowerShell — lectoren:

$pw = ConvertTo-SecureString "TestTest2025" -AsPlainText -Force $lect = "OU=Lectoren,DC=pxldigital,DC=local" @( @{Name="Annelies Verbruggen"; Sam="annelies.verbruggen"}, @{Name="Tom De Wilde"; Sam="tom.de.wilde"}, @{Name="Sofie Maes"; Sam="sofie.maes"}, @{Name="Bram Van Acker"; Sam="bram.van.acker"}, @{Name="Liesbeth Peeters"; Sam="liesbeth.peeters"} ) | ForEach-Object { New-ADUser -Name $_.Name -SamAccountName $_.Sam -UserPrincipalName "$($_.Sam)@pxldigital.local" ` -Path $lect -AccountPassword $pw -Enabled $true }

Via PowerShell — studenten (voorbeeld voor 1SNEa):

$pw = ConvertTo-SecureString "TestTest2025" -AsPlainText -Force @( @{Name="Alex Janssens"; Sam="a.janssens"; OU="1SNEa"}, @{Name="Noor De Smet"; Sam="n.de.smet"; OU="1SNEa"} ) | ForEach-Object { New-ADUser -Name $_.Name -SamAccountName $_.Sam ` -Path "OU=$($_.OU),OU=Studenten,DC=pxldigital,DC=local" ` -AccountPassword $pw -Enabled $true }
Standaard wachtwoord voor iedereen: TestTest2025

Logon name syntax:

  • Lectoren: voornaam.naam (vb. Annelies Verbruggen → annelies.verbruggen)
  • Studenten: x.naam waarbij x = eerste letter van de voornaam (vb. Alex Janssens → a.janssens)
  • Bij namen uit meerdere woorden worden de woorden gescheiden door een punt (vb. Noor De Smet → n.de.smet)

Client joinen aan domein
Taak 09
Windows 11 client joinen aan het domein
config
›

Vereisten op de server:

  • Statisch IP-adres ingesteld op de DC
  • DNS verwijst naar zichzelf (127.0.0.1 of eigen IP)

Vereisten op de client (WINADV-PC1XX):

  • Statisch IP in hetzelfde subnet als de DC
  • DNS-server ingesteld op het IP-adres van de DC

Joinen aan het domein:

  • Settings → System → About → "Domain or workgroup"
  • Klik "Change" → selecteer Domain → vul in: pxldigital.local

  • Via PowerShell (op de client):

    Add-Computer -DomainName "pxldigital.local" -Credential (Get-Credential) -Restart
    Gebruik de domain Administrator-credentials
  • Je krijgt "Welkom bij het domein pxldigital.local" → OK → Restart

Computer verplaatsen naar OU=Laptops:

  • Na het joinen staat de computer standaard in de container Computers
  • Open ADUC → zoek je computer in Computers
  • Rechtsklik → Move → selecteer OU=Laptops

    • Via PowerShell (op de DC):

    $pc = Get-ADComputer "WINADV-PC1XX" Move-ADObject -Identity $pc -TargetPath "OU=Laptops,DC=pxldigital,DC=local"
AGDLP
Taak 10
AGDLP — Domain Local Groups aanmaken en koppelen
configtheorie
›

AGDLP = Accounts → Global groups → Domain Local groups → Permissions. Dit is de Microsoft best-practice voor rechtenbeheer.

Waarom AGDLP?Door accounts in Global Groups te steken en die aan Domain Local Groups te koppelen, beheer je rechten centraal. Je past nooit individuele gebruikers aan — alleen de groepskoppeling.

Stap 1 — Domain Local Groups aanmaken

Voor elke bestaande GL group maak je een DL group aan met dezelfde naam maar met prefix DL_ in plaats van GL_. Group scope = Domain Local, type = Security.

Domain Local GroupBijhorende Global Group
DL_All_LectorsGL_All_Lectors
DL_All_StudentsGL_All_Students
DL_1SNEaGL_1SNEa
DL_1SNEbGL_1SNEb
DL_1SNEcGL_1SNEc
DL_1SNEdGL_1SNEd
DL_1SNEeGL_1SNEe

Via PowerShell — DL groups aanmaken en koppelen:

$grp = "OU=Groups,DC=pxldigital,DC=local" foreach ($naam in "DL_All_Lectors","DL_All_Students","DL_1SNEa","DL_1SNEb","DL_1SNEc","DL_1SNEd","DL_1SNEe") { New-ADGroup -Name $naam -GroupScope DomainLocal -GroupCategory Security -Path $grp } $klassen = "All_Lectors","All_Students","1SNEa","1SNEb","1SNEc","1SNEd","1SNEe" foreach ($k in $klassen) { Add-ADGroupMember -Identity "DL_$k" -Members "GL_$k" }

Stap 2 — GL groups toevoegen als member van de DL group

  • Open de DL group → Members → Add → voeg de bijhorende GL group toe
  • Doe dit voor alle 7 koppels
