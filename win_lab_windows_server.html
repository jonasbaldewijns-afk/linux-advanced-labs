CAL-types identificeren en toepassen
theorie

Een Client Access License (CAL) is vereist voor elke gebruiker of apparaat dat verbinding maakt met Windows Server.

CAL-typeGebonden aanWanneer gebruiken
User CALGebruikerGebruiker werkt op meerdere toestellen
Device CALApparaatMeerdere users op 1 toestel (callcenter)
RDS CALSessieRemote Desktop Services
External ConnectorExternKlanten/partners zonder eigen CAL
⚠ Let op — CAL's zijn geen software die je installeert — het is een juridisch toegangsrecht. Je moet ze kunnen aantonen bij een audit.

Taak 04
VM aanmaken in VMware voor Windows Server 2025
installatie
›

Maak een nieuwe VM aan in VMware Workstation met de juiste instellingen:

  • File → New Virtual Machine → Custom (Advanced)
  • Hardware compatibility: VMware Workstation 17.5 or later
  • I will install the operating system later
  • Guest OS: Windows Server 2022 (of 2025 indien beschikbaar)
  • Firmware: UEFI
  • Memory: 4096 MB
  • Network: Host Only
  • SCSI: LSI Logic SAS
  • Disk: 60 GB, single file
⚠ Let op — Gebruik UEFI, niet Legacy BIOS. Windows Server 2025 vereist dit.
Taak 05
Windows Server 2025 installeren (WINADV-DC1XX)
installatie
›

Installeer Windows Server 2025 via de ISO. De server moet in het Engels geïnstalleerd zijn.

  • Koppel de ISO aan de VM en start op
  • Kies taal: English — dit is een examenvereiste
  • Kies: Windows Server 2025 Datacenter Evaluation (Desktop Experience)
  • Installatietype: Custom
  • Selecteer de virtuele schijf en installeer
  • Stel na herstart een Administrator-wachtwoord in

Servernaam instellen:

  • Open Settings → System → About → "Rename this PC"
  • Naam: WINADV-DC1XX waarbij XX = jouw initialen (vb. Jonas Baldewijns → WINADV-DC1JB)
  • Herstart de server

Via PowerShell:

Rename-Computer -NewName "WINADV-DC1JB" -Restart

Vervang JB door jouw initialen. De server herstart automatisch na uitvoering.

Taak 06
VMware Tools installeren op de server
installatie
›

VMware Tools verbetert de integratie tussen host en VM (clipboard, schermresolutie, muis).

  • In VMware: VM → Install VMware Tools
  • In de VM: open de D:-schijf die verschijnt
  • Voer setup64.exe uit → Typical install → Next → Install → Finish → Reboot
✔ VerificatieNa herstart past de schermresolutie zich automatisch aan en werkt het clipboard tussen host en VM.
Installatie Windows 11 Client
Taak 07
Windows 11 client installeren (WINADV-PC1XX)
installatie
›

Installeer een Windows 11 Enterprise of Education 25H2 client. De client moet in het Nederlands geïnstalleerd zijn.

  • Maak een nieuwe VM aan in VMware (gelijkaardige specs als de server, min. 4GB RAM)
  • Koppel de Windows 11 ISO aan de VM
  • Kies taal: Nederlands — dit is een examenvereiste
  • Installeer Windows 11 Enterprise of Education (25H2)
  • Stel een lokaal account in tijdens de setup

Computernaam instellen:

  • Settings → System → About → "Rename this PC"
  • Naam: WINADV-PC1XX waarbij XX = jouw initialen (vb. WINADV-PC1JB)
  • Herstart de client

Via PowerShell:

Rename-Computer -NewName "WINADV-PC1JB" -Restart

VMware Tools installeren:

  • VM → Install VMware Tools → setup64.exe → Typical → Reboot
ℹ ISO downloaden — De Windows 11 ISO is beschikbaar via Windows Essentials op de PXL-omgeving. Vraag de link op via de cursus of je lector.
