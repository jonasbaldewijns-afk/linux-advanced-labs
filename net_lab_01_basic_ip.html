Lab 01 · Networks Advanced

Basic Device IP Configuration

Configureer IP-adressering, SSH, DHCP en basisbeveiliging op Cisco-apparaten in Packet Tracer. De fundering voor alle volgende labs.

Opstel
Taak 01
Topologie opbouwen in Packet Tracer
packet traceropstel
›

Bouw de onderstaande topologie op in Packet Tracer vóór je begint met configureren.

Apparaten:

  • 1x Router 2911 (R1)
  • 2x Switch 2960-24TT (SW1, SW2)
  • 2x PC (PC0, PC1)
  • 1x Server (Server0 — DHCP/DNS/TFTP)

Verbindingstabel:

Kabeltypes in PTStraight-through: PC/server → switch, switch → router. Cross-over: switch → switch, router → router (Ethernet). Automatisch: PT detecteert het juiste type als je "Automatically Choose" selecteert.
⚠ Packet TracerIn Packet Tracer genereert crypto key generate rsa modulus 2048 een sleutel zonder interactieve bevestiging. Typ het commando volledig in — PT voert het direct uit.
Configuratie
Taak 02
Basisconfiguratie op alle apparaten
cisco iosconfig
›

Voer op elk apparaat (R1, SW1, SW2) de volgende basisconfiguratie uit. Start altijd met enable en daarna configure terminal.

hostname R1 no ip domain-lookup enable secret cisco line con 0 password cisco login logging synchronous exit line vty 0 15 password cisco login exit service password-encryption banner motd # Ongeautoriseerde toegang verboden # copy running-config startup-config
Waarom no ip domain-lookup?Zonder dit commando interpreteert de router elke typo als een hostnaam en probeert hij die op te lossen via DNS — dit geeft een vervelende vertraging. no ip domain-lookup schakelt dat uit.
⚠ enable secret vs enable password — Gebruik altijd enable secret. Dit slaat het wachtwoord op als MD5-hash. enable password is onversleuteld en wordt nooit meer gebruikt.
Taak 03
SSH configureren op router en switches
cisco iossecurity
›

SSH versleutelt het beheerverkeer. Telnet stuurt alles in plaintext — gebruik het nooit in productie.

ip domain-name pxl.local crypto key generate rsa modulus 2048 ip ssh version 2 username admin privilege 15 secret cisco line vty 0 15 transport input ssh login local exit
ℹ Packet Tracer — Na crypto key generate rsa modulus 2048 vraagt PT niet om bevestiging. De sleutel wordt direct aangemaakt. Controleer met show ip ssh of SSH versie 2 actief is.
✓ Verificatieshow ip ssh — SSH versie en status
show users — actieve sessies
Taak 04
IP-adressering op router-interfaces
cisco iosconfig
›

Stel IP-adressen in op de router-interfaces. Gebruik het schema hieronder.

InterfaceIP-adresSubnetBeschrijving
R1 Gi0/0192.168.1.1255.255.255.0LAN naar SW1
R1 Gi0/1192.168.2.1255.255.255.0LAN naar SW2
interface GigabitEthernet0/0 ip address 192.168.1.1 255.255.255.0 description Naar SW1 no shutdown exit interface GigabitEthernet0/1 ip address 192.168.2.1 255.255.255.0 description Naar SW2 no shutdown exit

✓ Verificatieshow ip interface brief — toont alle interfaces: status moet up/up zijn
Taak 05
Switch management-IP instellen
cisco iosconfig
›

Een switch heeft standaard geen IP-adres. Voor SSH-beheer stel je een IP in op de management-VLAN (VLAN 1 of een apart management-VLAN).

! Op SW1 interface vlan 1 ip address 192.168.1.2 255.255.255.0 no shutdown exit ip default-gateway 192.168.1.1 ! Op SW2 interface vlan 1 ip address 192.168.2.2 255.255.255.0 no shutdown exit ip default-gateway 192.168.2.1
ℹ ip default-gateway — Een switch routeert zelf niet. De default-gateway vertelt de switch waar hij pakketten naartoe moet sturen die buiten zijn eigen subnet vallen (bijv. voor SSH vanuit een ander netwerk).
Taak 06
DHCP configureren op de router
cisco iosconfig
›

De router deelt automatisch IP-adressen uit aan PC0 en PC1.

! Statische adressen uitsluiten van DHCP ip dhcp excluded-address 192.168.1.1 192.168.1.10 ip dhcp excluded-address 192.168.2.1 192.168.2.10 ! DHCP pool voor netwerk 1 ip dhcp pool LAN1 network 192.168.1.0 255.255.255.0 default-router 192.168.1.1 dns-server 192.168.1.254 exit ! DHCP pool voor netwerk 2 ip dhcp pool LAN2 network 192.168.2.0 255.255.255.0 default-router 192.168.2.1 dns-server 192.168.1.254 exit

Stel PC0 en PC1 in op DHCP: klik op de PC in PT → Desktop → IP Configuration → DHCP.

✓ Verificatieshow ip dhcp binding — welke PC heeft welk IP gekregen
show ip dhcp pool — pool-statistieken
Taak 07
Connectiviteit testen
verificatie
›

Test systematisch van dichtbij naar ver. In PT gebruik je de simulation mode of de ping opdracht in de CLI van een apparaat.

! Op R1 — ping naar SW1 management ping 192.168.1.2 ! Op R1 — ping naar PC0 (moet IP gekregen hebben via DHCP) ping 192.168.1.11 ! Traceroute traceroute 192.168.2.11 ! Nuttige show-commando's show ip interface brief show arp show ip route show running-config
ℹ PT tip — Simulation modeKlik rechtsonder op "Simulation" en voeg een PDU toe (Simple PDU of Complex PDU) om pakketten visueel te volgen. Zo zie je exact welk pad een pakket neemt en waar het stopt.
Taak 08
Configuratie opslaan naar TFTP-server
cisco iosconfig
›

De running-config (RAM) gaat verloren bij een reboot. Sla altijd op naar startup-config (NVRAM) en maak een externe backup.

! Stap 1: opslaan in NVRAM copy running-config startup-config ! Stap 2: backup naar TFTP (Server0 = 192.168.1.254) copy running-config tftp ! PT vraagt: Address or name of remote host? 192.168.1.254 ! PT vraagt: Destination filename? R1-backup.txt

Activeer de TFTP-service op Server0 in PT: klik op Server0 → Services → TFTP → On.

✓ Verificatieshow startup-config — toont wat in NVRAM staat
Op Server0 in PT: Services → TFTP → controleer of het bestand er staat
