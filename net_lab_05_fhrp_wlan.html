FHRP + WLAN

Bouw verder op Lab 04 met een Wireless LAN Controller, Access Points en SSID-configuratie. Clients verbinden draadloos via WPA2.

Apparaten:

Taak 03
DHCP scope voor Access Points
cisco iosconfig
›

Lightweight APs starten op via DHCP en zoeken dan automatisch de WLC. De DHCP-pool moet het WLC-IP meegeven via optie 43.

! Op R1 — DHCP scope voor Access Points (VLAN 30) ip dhcp excluded-address 192.168.30.1 192.168.30.10 ip dhcp pool ACCESS-POINTS network 192.168.30.0 255.255.255.0 default-router 192.168.30.1 option 43 ascii 192.168.30.100 exit ! SVI voor VLAN 30 op SW1 (als L3 switch) of relay op R1 interface vlan 30 ip address 192.168.30.1 255.255.255.0 no shutdown exit
DHCP option 43Vertelt de AP het IP-adres van de WLC. Zonder optie 43 kan de AP de WLC niet vinden. In PT kan de AP ook automatisch de WLC vinden via broadcast als ze in hetzelfde subnet zitten.

Taak 05
WLC IP-adres instellen
config
›

De WLC heeft een management-IP nodig in het AP-VLAN.

In Packet Tracer: klik op de WLC → tabblad Config → Interface → stel in:

  • Management IP: 192.168.30.100
  • Subnet mask: 255.255.255.0
  • Default gateway: 192.168.30.1
ℹ WLC in Packet TracerDe GUI-tab van de WLC in PT is vereenvoudigd ten opzichte van een echte WLC. Je ziet een grafische interface maar met minder opties dan in realiteit. Zoek in PT naar het tabblad "GUI" op het WLC-apparaat voor de web-interface.
Taak 06
WLAN aanmaken op de WLC
config
›

Een WLAN-profiel koppelt een SSID aan een VLAN en beveiligingsinstelling.

In PT → WLC → GUI → WLANs → Create New:

  • Profile Name: PXL-Students
  • SSID: PXL-Students
  • Status: Enabled
  • Security: WPA2 Personal
  • Passphrase: cisco12345
  • VLAN: 10 (Sales/Students)
WPA2 Personal vs EnterprisePersonal (PSK): één gedeeld wachtwoord voor iedereen — eenvoudig maar minder veilig. Enterprise (802.1X): iedereen heeft eigen credentials via een RADIUS-server — veiliger en auditable. In schoollabs wordt meestal Personal gebruikt voor eenvoud.

Taak 09
Failover testen met draadloze client
verificatie
›

Test of de draadloze client online blijft als R1 (de actieve HSRP-router) uitvalt.

  1. Zet R1 uit in PT (Physical tab → power off)
  2. Wacht 10-15 seconden (HSRP holddown timer)
  3. Controleer: show standby brief op R2 — moet "Active" tonen
  4. Ping van de Laptop naar 192.168.10.1 — moet werken
  5. Zet R1 terug aan — R1 herneemt de Active-rol (preempt)
Taak 10
(Optioneel) WPA2-Enterprise met RADIUS
security
›

WPA2-Enterprise gebruikt een RADIUS-server zodat elke gebruiker zijn eigen credentials heeft.

  1. Voeg een Server toe aan de topologie
  2. Server → Services → AAA: zet aan, voeg gebruikers toe
  3. WLC → Security → RADIUS: voeg server-IP toe
  4. WLAN → Security: verander van WPA2-Personal naar WPA2-Enterprise
  5. Laptop: verbind met credentials i.p.v. wachtwoord
ℹ 802.1X authenticatieproces1. Client vraagt verbinding aan (Supplicant). 2. AP stuurt door naar WLC (Authenticator). 3. WLC vraagt RADIUS (Authentication Server). 4. RADIUS valideert credentials. 5. Toegang verleend of geweigerd.
